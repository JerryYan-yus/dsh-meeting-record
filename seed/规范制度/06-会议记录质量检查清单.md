# 会议记录质量检查清单

生成或定稿前逐项核对：

## 一、基本信息
- [ ] 会议类型与材料一致
- [ ] 时间、地点完整
- [ ] 主持人、记录人明确
- [ ] 应到、实到人数与参会人员一致

## 二、程序
- [ ] 需要表决的事项有表决方式和票数
- [ ] 发展党员、选举等专项流程步骤完整
- [ ] 到会人数符合开会要求
- [ ] 公示、报批、谈话等后续安排明确

## 三、内容
- [ ] 第一议题在前，其他议题顺序合理
- [ ] 每个议题有要点和逐人发言
- [ ] 一人一段、段间空行
- [ ] 不编造发言、票数、决议
- [ ] 姓名、职务、数字前后一致

## 四、决议与任务
- [ ] 决议一条一项
- [ ] 责任人和完成时限明确，无法确定标注【待核对】
- [ ] 需要上报、公示、归档的事项已注明

## 五、篇幅
- [ ] 符合设置的短/中/长要求
- [ ] 不注水、不重复
