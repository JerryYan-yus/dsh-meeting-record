# 文件预处理与入库

## 用户只丢文件、未提会议记录

1. 先 `file_preprocess(path)`；不要默认生成会议记录。
2. 回复短卡：类型初判、标题、日期、文号/发文单位、一句话概括、3–5 个要点、建议存放位置。
3. 末尾只问：“这份文件要：1. 存入知识库；2. 仅本次参考；3. 按它生成会议记录/写材料？”
4. 选 1：
   - 有本地文件路径：`knowledge_import_files`（≤20 个/次），服务端存全文，模型不传全文；
   - 只有粘贴文本：`knowledge_save`；
   - 分类：政策/通知/上级文件→reference；总结/报告/方案→material；台账/日常→daily。
5. 选 2：直接回答，不保存；选 3：进入会议/材料流程，先确认类型。
6. 批量文件：先列清单，分批导入，不必逐个 `file_preprocess`。

## 扫描 PDF / 图片

- `file_preprocess` 返回 `needsOcr`/`needsVision` 时，不要调用 LibreOffice，不要自动识图。
- 三选一：
  1. 提供文字版（首选）；
  2. 1–3 页截图识图（用户明确选；约 1k–3k token/页；只提取关键信息）；
  3. 仅登记文件信息。
- 整本几十页不要自动识图；数字、姓名、文号、票数必须用户核对。
